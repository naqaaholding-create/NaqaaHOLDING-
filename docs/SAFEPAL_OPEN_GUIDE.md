# فتح NAQAA من داخل SafePal

## المسار الصحيح
1. افتح SafePal على الهاتف.
2. افتح المتصفح داخل SafePal.
3. افتح موقع NAQAA المنشور عبر HTTPS.
4. افتح صفحة Wallet.
5. اضغط «اتصال SafePal / المتصفح».
6. وافق على طلب الاتصال عندما يظهر من SafePal.
7. يجب أن يعيد SafePal عنوانًا عامًا يبدأ بـ 0x مع BNB Smart Chain / Chain ID 56.
8. اضغط «ربط العنوان» داخل NAQAA.

## ما يتم حفظه
- العنوان العام فقط.
- الشبكة: BEP20 / BNB Smart Chain.
- اسم المزود: SafePal.

## ممنوع
لا تطلب الصفحة Seed Phrase أو Private Key أو كلمة مرور SafePal.

## ملاحظة
GitHub Pages يجب أن يكون مفعّلًا للمستودع وأن تكون الصفحة المنشورة هي النسخة الحالية من static/wallet.html. تكامل الهاتف الكامل عبر WalletConnect/Reown يحتاج مشروعًا/معرّفًا رسميًا وتكاملًا مخصصًا للتطبيق المحمول؛ زر المتصفح الحالي يعتمد على EIP-1193.
